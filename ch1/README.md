# Chapter 01
문제 1. 16MB 메모리의 주소 범위를 구하시오.
16MB = 16 x 1024 x 1024 = 2^24Byte
따라서 주소의 범위는 0x000000 ~ 0xFFFFFF이다.
-----------
문제 2. 변수의 주소를 설명하시오.
변수가 차지하고 있는 공간의 시작 번지(가장 작은 주소)
-----------
문제 3. 변수의 주소의 자료형은 무엇인가?
변수의 주소의 자료형이란 (주소가 가리키는 변수의 자료형)*
-----------
문제 4. 포인터란 무엇인가?
주소를 저장하기 위한 변수(주소형 변수)
-----------
문제 5. 포인터의 자료형은 무엇인가?
포인터에 저장될 주소의 자료형(자료형*)
-----------
문제 6. 변수의 주소를 int형 변수에 저장하면 어떻게 되는가?
변수의 주소를 포인터가 아닌 int형 변수에 저장하면 오류가 난다.
