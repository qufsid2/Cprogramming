## 실습과제 1
### 16MB 메모리의 주소 범위를 구하시오.
- 16MB = 16 x 1024 x 1024 = 2^24Byte \
따라서 주소의 범위는 0x000000 ~ 0xFFFFFF이다.
-----------
### 변수의 주소를 설명하시오.
- 변수가 차지하고 있는 공간의 시작 번지(가장 작은 주소)
-----------
### 변수의 주소의 자료형은 무엇인가?
- 변수의 주소의 자료형이란 (주소가 가리키는 변수의 자료형)*
-----------
### 포인터란 무엇인가?
- 주소를 저장하기 위한 변수(주소형 변수)
-----------
### 포인터의 자료형은 무엇인가?
- 포인터에 저장될 주소의 자료형(자료형*)
-----------
### 변수의 주소를 int형 변수에 저장하면 어떻게 되는가?
- 변수의 주소를 포인터가 아닌 int형 변수에 저장하면 오류가 난다.
-----------
## 실습과제 2
```
double* pt;
```

-----------
### 다음에서 pt에 저장될 주소의 자료형은 무엇인가?

-----------
### 다음에서 pt의 자료형은 무엇인가?
- double* 형
-----------

- pt가 double형 데이터를 가리킨다는 의미

## 실습과제 4
### 다음 코드처럼 변수 a, b, c를 선언하고 각 변수의 주소를 주소연산자(&)를 이용하여 화면에 다음처럼 출력하라.
```
char a = 'A';
int b = 36;
double c = 3.141592;
```

▼ 소스코드 설명
```
#include <stdio.h>
```
- scanf, printf, 등 여러가지 라이브러리가 들어있는 stdio.h를 포함해라.
```
int main(void)
```
- 메인함수 시작
```
char a = 'A';
```
- a라는 문자형 변수를 선언하고 'A'라는 문자를 저장
```
int b = 36;
```
- b라는 정수형 변수를 선언하고 36이라는 값을 저장
```
double c = 3.141592;
```
- c라는 실수형 변수를 선언하고 3.141592라는 값을 저장
```
printf("char형 변수 a의 주소: %x \n", &a);
```
- a의 메모리 주소 &a 16진수로 출력
```
printf("int형 변수 b의 주소: %x \n", &b);
```
- b의 메모리 주소 &b를 16진수로 출력
```
printf("double형 변수 c의 주소: %x \n", &c);
```
- c의 메모리 주소 &c를 16진수로 출력
```
return 0;
```
- 0을 반환하고 메인함수 정상 종료
