# Chapter 13-1
## 실습과제 1

* 배열 첫번째 요소의 주소
* 배열 표현과 포인트(주소) 표현이 변환 공식

|  | 배열표현 | 포인터(주소) 표현 |
| :--: | :----: | :----------: |
| 배열요소의 값 | a[i] | *(a + i) |
| 배열요소의 주소 | &a[i] | a + i |

* 배열의 첫 번째 요소의 주소에 (인덱스 × 자료형의 크기)를 더하여 원하는 배열 원소의 주소를 계산할 수 있다.
* 배열의 첫 번째 요소의 주소를 포인터에 저장한 후, 포인터에 인덱스를 더하고 역참조(*)하면 각 배열 원소의 값을 얻을 수 있다.
* 포인터에 대해 가능한 연산의 종류와 의미

| 수식(p:포인터, n:정수) | 의미 |
| :----------: | :----------: |
| p + n | p + n * (포인터가 가리키는 자료형의 크기) |
| p - n | p - n * (포인터가 가리키는 자료형의 크기) |
| p++ | p = p + (포인터가 가리키는 자료형의 크기) |
| p-- | p = p - (포인터가 가리키는 자료형의 크기) |

* 포인터 연산은 가리키는 자료형의 크기를 기준으로 이동하도록 정의하여 배열의 각 원소에 쉽게 접근할 수 있도록 하기 위함이다.

```

```
int sum = 0, i, average;
```

```
for (i = 0; i < 5; i++) {

- 성적 입력하라는 메시지 출력
- 성적 입력
- 성적 더하기

average = sum / 5.0;
```
전체 성적의 평균 저장
```
printf("성적 평균= %d\n", average);
```
성적 평균 출력

```

## 실습과제 3

* a++과 ++a는 순서의 차이가 있다. a++을 출력했을 때 값이 출력되는 게 우선이지만, ++a를 출력할 경우 1을 더하는 것이 우선이 된다.
* 배열의 이름은 증감 연산으로 변경할 수 없기 때문에 a++는 사용할 수 없다. 그렇기 때문에 포인터 변수 p를 선언하여 배열의 시작 주소를 저장하고, *p++를 이용한다.

▼ 소스코드 설명
```
#include <stdio.h>
```
- scanf, printf, 등 여러가지 라이브러리가 들어있는 stdio.h를 포함해라.
```
int main(void)
```
- 메인함수 시작
```
int a[] = { 10, 20, 30 };
```
- a라는 배열을 10, 20, 30으로 초기화
```
int* p = &a;
```
- a의 주소를 p에 저장
```
int i, sum = 0;
```
- i, sum이라는 변수를 선언하고 sum에 0을 저장
```
for (i = 0; i < 3; i++)
  sum += *p++;
```
- 3번 반복
- a의 값을 sum에 더하기
```
printf("sum:%d\n", sum);
```
- 총합 출력
```
return 0;
```
- 0을 반환하고 메인함수 정상 종료

## 실습과제 4

▼ 소스코드 설명
```
#include <stdio.h>
```
- scanf, printf, 등 여러가지 라이브러리가 들어있는 stdio.h를 포함해라.
```
int main(void)
```
- 메인함수 시작
```
double arr[5];
```
- 5개의 방을 가진 실수형 arr 배열 선언
```
double* ptr;
```
- ptr이라는 포인터 선언
```
int i;
```
- i라는 정수형 변수 선언
```
ptr = arr;
```
- arr의 주소를 ptr에 저장
```
for (i = 0; i < 5; i++) {
  printf("실수 입력: ");
  scanf("%lf", ptr++);
}
```
- 5번 반복
- 실수 입력하라는 메시지 출력
- 실수 입력
```
ptr = arr;
```
- arr의 주소를 ptr에 저장
```
for (i = 0; i < 5; i++) {
  *ptr += 2;
  ptr++;
}
```
- 5번 저장
- 입력된 값에 +2
- ptr = ptr + 1;
```
ptr = arr;
```
- arr의 주소를 ptr에 저장
```
printf("\n2씩 증가된 배열의 값:\n");
```
- ptr 값 출력 메시지 출력
```
for (i = 0; i < 5; i++)
  printf("%.2f ", *ptr++);
```
- 5번 반복
- ptr 값 출력
```

```
- 0을 반환하고 메인함수 정상 종료
